# Aisha Haris - Personal Portfolio

## Project Description
This is my personal portfolio website created to showcase my skills, projects, education, experience, and professional information as a Frontend Web Developer.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons

## Features
- Responsive and mobile-friendly design
- Home / Hero section
- About Me section
- Skills section with dynamic data
- Projects section with project details modal
- Education and Experience sections
- Contact section with contact form
- Dark / Light mode
- Interactive animations
- Responsive navigation bar

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. The portfolio website will run locally.
